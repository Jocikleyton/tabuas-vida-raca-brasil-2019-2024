# Dicionário de Variáveis — Tábuas de Vida Abreviadas (2019–2024)

| Coluna | Descrição Demográfica |
| :--- | :--- |
| `ano` | Ano de referência das estimativas (2019 a 2024) |
| `regiao` | Âmbito geográfico (Brasil, Norte, Nordeste, Sudeste, Sul, Centro-Oeste) |
| `sexo` | Sexo (Masculino, Feminino) |
| `raca_cor` | Categoria de cor ou raça (Branca, Preta, Parda, Amarela, Indígena) |
| `metodo` | Procedimento de estimação (Sem Ajuste vs. Calibrado MII) |
| `x` | Idade exata no início do grupo etário (0, 1, 5, 10, ..., 80, 85+) |
| `nMx` | Taxa central de mortalidade no grupo etário |
| `nqx` | Probabilidade de morte entre as idades x e x+n |
| `lx` | Sobreviventes à idade exata x (radix = 100.000) |
| `ndx` | Óbitos entre as idades x e x+n na coorte sintética |
| `nLx` | Anos-pessoa vividos pela coorte no grupo etário |
| `Tx` | Total de anos-pessoa vividos acima da idade x |
| `ex` | Expectativa de vida à idade x (e0 = expectativa de vida ao nascer) |
